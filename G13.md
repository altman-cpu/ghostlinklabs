# G13 — Command and definition wall

A local, readable record of the commands discussed in this session. Search terms
are represented by `SEARCH_TERM` so this document does not reintroduce the names
previously requested for removal. These examples are not executed automatically.

## Garage wall: commands

### Check repository changes

```bash
git status --short
```

Shows a compact list of changes in the working tree.

### Find tracked filenames

```bash
git ls-files | grep -iE 'SEARCH_TERM' | head -80
```

Lists up to 80 tracked filenames matching the supplied pattern, ignoring case.
Replace `SEARCH_TERM` with your own pattern before use.

### Check for a PDF text tool

```bash
command -v pdftotext
```

Prints the executable's path if the program is available on the shell's path.

### Count files by extension

```bash
python - <<'PY'
from pathlib import Path

for ext in ('*.pdf', '*.docx', '*.zip', '*.tgz'):
    print(ext, len(list(Path('.').rglob(ext))))
PY
```

Counts matching paths recursively from the current directory. This count can
include files that Git ignores.

### Find filenames containing text

```bash
rg -i -l 'SEARCH_TERM' --glob '!*.pdf' --glob '!*.docx' \
  --glob '!*.zip' --glob '!*.tgz' . | head -100
```

Shows up to 100 matching filenames. The excluded extensions require different
inspection methods; ripgrep's normal ignore and hidden-file rules also apply.

### Reference: Python inspection script

This is a sanitized version of the earlier inspection command. It requires
`pypdf` to be installed in the indicated temporary location and a meaningful
search pattern in place of `SEARCH_TERM`. It reads files; it does not modify
them. Avoid running searches against archives you do not trust.

```bash
PYTHONPATH=/tmp/ghostlink-pdf-search python - <<'PY'
from pathlib import Path
import zipfile, tarfile, re
from pypdf import PdfReader

pat = re.compile(r'SEARCH_TERM', re.I)
for path in Path('.').rglob('*'):
    if not path.is_file() or '.git' in path.parts:
        continue
    if path.suffix.lower() == '.pdf':
        try:
            reader = PdfReader(str(path))
            for number, page in enumerate(reader.pages, 1):
                if pat.search(page.extract_text() or ''):
                    print(f'{path}:page {number}')
        except Exception as exc:
            print(f'Unable to inspect {path}: {exc}')
    elif path.suffix.lower() in ('.zip', '.docx', '.tgz'):
        try:
            if zipfile.is_zipfile(path):
                with zipfile.ZipFile(path) as archive:
                    for name in archive.namelist():
                        if pat.search(name) or (not name.endswith('/') and
                                pat.search(archive.read(name).decode('utf-8', errors='ignore'))):
                            print(f'{path}:{name}')
            elif tarfile.is_tarfile(path):
                with tarfile.open(path) as archive:
                    for member in archive:
                        if member.isfile():
                            content = archive.extractfile(member).read().decode('utf-8', errors='ignore')
                            if pat.search(member.name) or pat.search(content):
                                print(f'{path}:{member.name}')
        except Exception as exc:
            print(f'Unable to inspect {path}: {exc}')
PY
```
